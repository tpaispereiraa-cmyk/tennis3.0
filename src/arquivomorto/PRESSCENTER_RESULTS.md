# PRESSENTER — RESULTS

## Antes

- 3 abas separadas no BroadcastUniverse: NOTÍCIAS, JORNAL, ENTREVISTAS
- NOTÍCIAS: lista básica de eventos (lesões, aposentadorias) sem editorial
- JORNAL: feed de artigos do NewsEngine em layout simples
- ENTREVISTAS: sala de imprensa isolada das notícias
- Nenhuma conexão visual entre os três sistemas

## Depois

- 1 aba: IMPRENSA
- Central unificada com identidade editorial própria ("REDAÇÃO DO CIRCUITO")
- 5 mesas editoriais com UI distinta por seção
- Filtro global por jornalista (JournalistStrip)
- Modo leitura imersivo com pull quote e tipografia editorial

## O que muda para o jogador

| Feature | Antes | Depois |
|---|---|---|
| Acessar notícias | 2-3 cliques em abas diferentes | 1 aba, navegação lateral |
| Ler artigo completo | Layout básico sem destaque | Modo leitura com pull quote, headline grande, deck |
| Filtrar por jornalista | Não existia | JournalistStrip com contagem de artigos |
| Rumores/gossip | Misturado com todas as notícias | Bastidores — mesa dedicada com visual distinto |
| Análises táticas | Sem separação | Mesa Análise com layout específico |
| Histórico | Não existia | Arquivo com filtro por temporada e busca |
| Entrevistas | Tab separada, sem contexto de notícias | Mesa Entrevistas dentro da Redação |

## Detalhes visuais

- Ticker automático com últimas manchetes
- Dot pulsante "LIVE" no header
- Cada mesa tem cor editorial própria (gold para Manchetes, purple para Bastidores, blue para Análise)
- Pull quotes extraídos automaticamente do body dos artigos
- JournalistStrip mostra jornalistas que mais publicaram com contagem
- Modo leitura: gradiente por superfície do torneio no header, blockquote estilizado, tags
